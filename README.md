# Asrafuzzaman Khan Nahin — research profile

A static, responsive research website for GitHub Pages. Open `index.html` directly or serve the repository with any static file server.

## Pages

- `index.html` — introduction and featured work
- `projects.html` — research projects
- `publications.html` — papers and manuscript status
- `contact.html` — email and academic profiles

The downloadable CV is in `assets/Asrafuzzaman-Khan-Nahin-CV.pdf`. Content was prepared from the October 2026 CV and application materials supplied for this project. Update the PDF and page text together when the record changes.

The site uses plain HTML, CSS, and a small JavaScript file for the mobile navigation. No build step is required.
